# V12 — интерактивная модель двигателя

Работающий 3D-двигатель V12 прямо в браузере: все 12 поршней, шатуны, клапаны и распредвалы
движутся, любую деталь можно рассмотреть вблизи, а время — замедлить до ×0,001.

## Как открыть

Сайт статический — сборка не нужна. Достаточно открыть `index.html` двойным кликом.
Или поднять любой локальный сервер:

```bash
python3 -m http.server 8000   # затем http://localhost:8000
```

Для публикации подойдёт GitHub Pages (Settings → Pages → Deploy from a branch → корень репозитория).

## Что умеет

- **Движение всех деталей**: коленвал, 12 поршней и шатунов, 48 клапанов с пружинами, 4 распредвала, маховик.
  Газ в цилиндрах меняет цвет по тактам (впуск → сжатие → рабочий ход → выпуск), на свечах видна искра.
- **Клик по детали** — камера подлетает к ней, остальное становится полупрозрачным; в карточке справа —
  описание, живые цифры (давление, скорость поршня, подъём клапана, наклон шатуна…) и график цикла цилиндра.
  Выбрать цилиндр можно и на карте тактов слева.
- **Время**: ползунок и кнопки ×1 … ×0,001, пауза, шаги по 10°, ползунок «Угол цикла» (0–720°) для
  разглядывания любой фазы. Отдельно — обороты (800–9000 об/мин) и прозрачность корпуса.
- **Камера**: левая кнопка — вращать, правая (или Shift) — сдвиг, колесо — масштаб; на телефоне —
  перетаскивание и щипок. Двойной клик — общий вид.
- **Клавиши**: `Пробел` — пауза, `←` `→` — шаг ±5°, `Esc` — снять выбор, `H` — общий вид.

## Как устроена модель

Параметры: 12 цилиндров, развал 60°, ⌀ 85,5 × 90 мм (6,2 л), степень сжатия 11:1, порядок работы
Б1-А3-Б3-А2-Б2-А1-Б6-А4-Б4-А5-Б5-А6 (вспышка каждые 60° поворота вала).

Положения не нарисованы вручную, а считаются из кинематики кривошипно-шатунного механизма:
положение поршня по углу вала и длине шатуна, угол шатуна, фазы клапанов. Подъём клапана
берётся из той же формы кулачка, что нарисована на валу, поэтому кулачок всегда касается толкателя.
Распредвалы вращаются вдвое медленнее коленвала. Давление в цилиндре — упрощённая модель
(политропа сжатия + горение по Вибе), для наглядности, а не для инженерных расчётов.

```
index.html        разметка и панели управления
css/style.css     оформление
js/engine.js      геометрия деталей, кинематика, такты, «фокус» на детали
js/app.js         сцена, камера, выбор деталей, интерфейс, график цикла
js/info.js        тексты описаний деталей
js/vendor/        three.js r149 (MIT), положен в репозиторий, чтобы сайт работал без интернета
```
